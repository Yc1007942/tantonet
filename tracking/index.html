Good To Know

What You Need. What You’ll See.

What You Need

The Container Number

The 11-character ISO code on the door of your container: four owner/operator letters, seven digits and a check digit. Your bill of lading number works too.

TAKU 2345678-1
What You’ll See

Activity, Date, Container

Activity — the latest recorded event on your container. Date — when that event was recorded. Container — the number as registered in the system.

Where It Comes From

The Live Schedule System

Tracking queries the same live system that publishes sailings and runs T-Link and the eTanto dashboard. If a container has no data yet, the local office can look it up for you.
