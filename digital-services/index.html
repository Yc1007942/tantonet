First Mover

Digital, Before It Was The Word.

Tanto has set the standard for IT innovation in Indonesian shipping since the company first introduced the SMS Release Order and the Online Container Information System in Indonesia — early digital tools that saved customers time and money, and a pattern that continues today across the T-Link app, the dashboard and the live schedule feed.

The wider ecosystem also includes ePresence for staff attendance and T-Trek for vehicle location — the same data discipline, applied to the people and assets that run the network.
